# Hi, I'm Jacek 👋

**GIS Developer from Wrocław, Poland** – bridging geomatics and software engineering.

I design and build GIS systems end to end: from requirements and BPMN process models, through spatial databases and backend services, to web map applications – plus spatial analysis and optimisation when a problem needs more than a map.

- 🗺️ **Web GIS:** React · TypeScript · ArcGIS Maps SDK for JavaScript
- ⚙️ **Backend:** Python · Django REST Framework · Celery · SQL Server · ArcGIS Server (map & geoprocessing services)
- 📐 **Spatial analysis:** ArcGIS Pro · ArcPy · QGIS / PyQGIS · network analysis · optimisation (ILP)
- 🌱 **Currently learning:** GeoPandas · PostGIS · GeoServer · Azure – follow the `urban-green-*` project series
- 🎓 MSc in Geomatics, Wrocław University of Science and Technology · background in land surveying
